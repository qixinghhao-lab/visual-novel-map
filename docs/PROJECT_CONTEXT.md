# Project Context

This project is a visual planning tool for long-form fiction. It focuses on structure-first workflows:

- Build a main storyline with chapter nodes, logic points, split segments, branches, and an overview minimap.
- Organize outline, characters, settings, world entries, prompt templates, and drafting interfaces in separate workbenches.
- Keep the initial project blank. The app should not ship with preset story content.
- Treat AI features as interface placeholders until a real backend/model integration is added.

For public documentation and setup, start with the repository `README.md`.
